## Butuh dari modul lain
- **P1 / S-C (rute rumah)**: `gabung_direktori` dari perekrut/perintah dan `gabung_lamaran` (tombol Lamar) belum punya rumah
  terdaftar -> Di Sini (kelas sama, satu GUI). Usul M06 `HubPages.daftarRumah(layar, tab, bagian, halaman, sub)` ->
  `luar/sekte_dunia`; mount M11 = `LembarHub.dari(Entri(SEKTE, "luar", 80, -, "gabung_direktori", {}))`, dan
  `gabung_politik`+`perang` -> `luar/perang` (Perguruanku).
- **P1**: LayarDirektori menggambar dengan kit screen/ui lewat `Page.lukis` + `fokusRing` (override drawBehind/masukan
  LayarTempatDasar) — pola untuk lembar lain; `uji ui skala` tidak berlaku padanya. `GulirIsi` (M10) dipakai M11, boleh
  dipindah ke screen/ui. `HubCardsPage` kasus glyph "sekte_diplomasi_rival" kini mati (tidak berbahaya).
- **M10 / P5**: `LangitScreen` Tetangga (43.12.1: Tetangga -> Sekte Dunia): klik baris -> `LuarPage.bukaSekte(id)`.
- **P5**: LayarLamaran masih teks kecil kit 38 (0.75-0.9); Seteru: judul "Sahabat" tanpa isi saat kosong.
- (info) kabar dunia Diplomasi masuk Catatan lewat `HallClient.sumberCatatan("diplomasi", ...)` (G37).
