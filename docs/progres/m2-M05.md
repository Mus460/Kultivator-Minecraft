## Keputusan kecil
- Ikhtisar = satu `Page` komposit; anak tidak terdaftar sendiri di `HubPages` (sub, bukan koin).
- Identitas hanya untuk pemilik aula; LambangOpen tak diminta lewat `IkhtisarPage.buka("identitas")` (menunggu HallInfo).
- Catatan tampil bila ada aula atau ada sumber terdaftar.
- `LayarKartu`: tab Shifu/Murid dilebur ke gulir Kartu (43.0.4); tombol Kartu 2 baris x 3.
