Scope (jadwal row 42K-C): `tools/kota_cakap_sumber/**` (author sources), data `percakapan/obrolan/*.json`; lang
`kota_hidup_cakap` only through `gen_kota_hidup_cakap.py` (42K-T) output. No Java. Targets: >= 900 frames, >= 2400 terminals.

## Format decision (session 2)
42K-T's generator docstring is the binding source format (`== id`, `||`, `~ f:` variants, per-rule `$slot:` lines, no
global slots). Session 1 had drafted in an own format: retired in the repo as
`tools/kota_cakap_sumber/{sumber.py,_slot.txt}.deactivation`. Drafting aid (scratchpad `w42kc/`, not shipped):
`asal/*.txt` compact drafts + global slot library `asal/_slot.txt`; `rakit.py <repo>` writes the binding
`tools/kota_cakap_sumber/<stem>.txt` (every slot declared per rule, draft header comments kept) and compiles them with the real
generator into a temp repo; `rakit.py <repo> gestur|data` checks gesture names and niat/topik ids against niat.json/topik.json;
`cekvar.py` id/en placeholder sets; `ubah.py` header rewrites; `obrolan.py <repo>` writes + checks the 8 scripts.
The repo .txt files are the source of truth.

## Butuh dari modul lain
- **42K-T (goldens):** the corpus changed after the goldens were written: re-run `python tools/gen_kota_hidup_cakap.py
  --golden-tulis` after a look. `tagih_utang.json` asks niat `TAGIH`, which is not in niat.json: use `PERMINTAAN_NPC` +
  topik `uang` (debt demand) or `KILAS_BALIK` + topik `kilas.utang_pemain` (reminder). `tutup.json` should pass a topik
  (`pamit`, `sabar_habis` or `marah`); without one the realiser falls back to all TUTUP rules.
- **42K-T / 42K (value provider of `Realisasi.Masukan.nilai`, looked up by slot name, then by `dari`):** fact slots use
  `fakta.subjek|objek|nilai|hariKejadian`; others `konteks.<k>` with k = tempat distrik titik arah jarak cuaca musim
  sekte_pelindung barang_murah barang_mahal tahun terakhir_jumpa pasangan anak sahabat musuh almarhum kekasih guru murid
  tetangga batas barang harga harga_tawar (plus 42K's `lawan waktu_lalu apa jumlah nama`). Frames whose slot is empty are
  skipped, so missing keys only narrow the choice.
- **42K:** POTONG rules are ids `potong.<sebab>` (bahaya pelanggan gong dipanggil anak sibuk), all niat POTONG without topik.
  Reaction steps of the gossip script carry `"fakta": "menonjol"` so their text can name the fact (topic = predicate topic,
  falling back to the no-topik reaction rules). Script start `syarat` is documentation only (ObrolanWarga picks kinds in code).
