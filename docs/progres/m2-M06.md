## Keputusan kecil (untuk F43-M1 / P4)
- Sub ke-4 `penerus` ditambahkan (Aulaku: pewaris + upacara + silsilah; Perguruanku: tab Suksesi). Alasan: 43.0.4 melarang
  bilah tab keempat; Balai Tetua punya 3 tab dan Politik 2 tab untuk satu sub `tetua`. Kini `tetua` = Jabatan + Laporan
  bertumpuk (Aulaku) / Majelis (Perguruanku), `penerus` = Penerus / Suksesi. Id `calon`/`pangkat`/`tetua` tetap.
- Sumber Perguruanku = lembar 41 dipasang lewat `LembarHub.dari(new HubPages.Entri(...))` tanpa `daftarLembar` (satu id
  halaman tidak bisa dua registrasi; registrasi kedua = koin ganda). Lembar 41 dari hub boleh bertindak (hanyaBaca false).
- `CandidateCard` tetap sebagai pelukis kartu (G09 menyebut `PemilihOrang` mode kartu, tetapi kit tidak punya mode itu).
- Teks kecil di LayarPolitik (0.6-0.9) dan `keterangan` kit 38 (0.75) belum disentuh: poles skala milik P4 / kit milik P1.

## Butuh dari modul lain
- **M05 (wajib untuk B1)**: `hall/HallScreen.java` baris `allPages.add(new CalonPage(this));` dan
  `allPages.add(new JenjangPage(this));` dihapus (keduanya kini `Page`, konstruktor tanpa argumen). Bila M05 tidak
  menyentuhnya, F43-M1 menghapus dua baris itu. `hall/HallUi` tetap dipakai CalonPage/CandidateCard/JenjangPage (jangan
  `.deactivation`). `OP_CLOSE` (lepas penonton aula orang lain) tetap urusan halaman Ikhtisar M05; Anggota hanya
  mengirim `OP_REFRESH`.
- **P1 / pemilik 43-S**: rute rumah untuk halaman komposit: lembar `gabung_pangkat` dan `gabung_politik` tab
  majelis/suksesi yang dibuka dari dunia/perintah (npcId -1 tanpa `OP_LIHAT`, mis. `LembarKartu` "lompat") kini jatuh ke Di
  Sini karena tidak ada `daftarLembar`. Usul: `HubPages.daftarRumah(layar, tab, bagian, halaman, sub)` yang dibaca
  `LembarHub.rumah`, lalu `UiTempatClient` membuka `Tujuan(bagian, halaman).sub(sub)`; AnggotaPage memakai halaman
  `LembarHub` yang sama (kunci layar|tab) sehingga isi konteks langsung tampil. Pemetaan: `gabung_pangkat` -> anggota/
  pangkat, `gabung_politik`+majelis -> anggota/tetua, +suksesi -> anggota/penerus.
- **S-A / P1 (opsional)**: rute `Halls.PAGE_CALON/JENJANG` sebaiknya memanggil `AnggotaPage.sumberAula()` sebelum
  `HubNav.buka` agar prasasti aula selalu membuka sumber Aulaku (sekarang mengikuti pilihan chip terakhir).
