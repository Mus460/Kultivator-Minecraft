## Keputusan kecil
- Harta memakai sub datar (titik, gua, pilih, kolam, lapak), bukan "kediaman | usaha" + tab lembar di dalamnya: itu
  tingkat 4 (43.0.4). Id sub = id tab lembar, sama dengan rute `UiTempatClient.rumah` (`Tujuan.sub(tab)`).
- Nama: "Gua Pribadi" (titik Gua Kediaman 19.3.5) vs "Gua Sekte" (gabung_kediaman) agar tidak dua "Gua Kediaman" (G63).
- Hapus titik gua = SegelKonfirmasi RINGAN (dulu klik kedua 3 s); sumpah Dao = SEDANG (43.5).

## Butuh dari modul lain
- **F43-M1 (host 43-S `screen/CultivationScreen.daftarBawaan()`)**: tambahkan dua baris setelah `ALKIMIA`:
  `HubPages.daftar(HubNav.DIRI, Urutan.ID_PUSAKA, Urutan.PUSAKA, dev.kultivator.client.tempa.PusakaPage::new);`
  `HubPages.daftar(HubNav.DIRI, Urutan.ID_HARTA, Urutan.HARTA, HartaPage::new);`
  (tanpa ini Pusaka dan Harta tidak punya koin; tidak ada berkas `*Client` milik M01).
- **M13 (`dunia/DuniaScreen`)**: hapus `new dev.kultivator.client.tempa.PusakaPage(screen)` dari daftar tablet (baris 68);
  PusakaPage kini `Page` tanpa argumen dan tinggal di Diri › Pusaka. Tanpa ini build gagal.
- **P1 / pemilik `LembarHub` (43-S)**: `LembarHub.rumah` hanya mengenal pendaftaran `daftarLembar`; halaman gabungan
  (Harta memasang dua lembar) tidak bisa menjadi rumah konteks dunia. Sekarang `gabung_kediaman` dari NPC dan
  `buku_kas` tab lapak dari dunia jatuh ke Di Sini / Sekte › Kas. Usul: `HubPages.daftarRumah(layar, tab, idHalaman)`
  (alias rumah tanpa koin) yang dipakai `rumah()`; Harta sudah memakai mount yang sama (`LembarHub.dari(Entri)` kunci
  layar|tab), jadi `isiKonteks` akan langsung mendarat di sub yang benar.
- **S-C / P1**: server membuka lembar 41 dari hub sebagai sesi berjangkar yang boleh menulis (`GabungLayar.daftar`
  `bukaDi`), tetapi `UiTempatClient.terima` menandainya `lihatSaja(dariHub)` -> Sewa/Perpanjang Gua Sekte dari Harta
  nonaktif. Periksa apakah lembar gabung dari hub harus tetap bisa menulis.
- **M17**: JalanPage dipasang di Diri › Jalan oleh host (tanpa Langkah, 43.5); M01 tidak menyentuh kelasnya.
- **P2**: uji skala 2/3/4 dan papan ketik Harta (titik: tombol di cincin Tab; sub lembar: fokus lembar).
