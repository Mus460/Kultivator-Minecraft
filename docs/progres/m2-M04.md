# m2-M04 — Daftar & Jaring (desain 43.16.2, gelombang 43-M1)

Halaman Murid › Daftar (ringkas | suasana | tangga) dan Murid › Jaring. Berkas milik: `sekte/mandiri/{MandiriBoardScreen,
MandiriClient}`, `sekte/kepribadian/{SuasanaScreen, KepribadianClient}`, `sekte/tangga/{TanggaCatatanScreen, TanggaClient}`,
`sekte/hubungan/{JaringScreen, HubunganClient}`, baru `sekte/hubungan/PelukisIkatan`; lang `gui43_m04`.
Tidak menjalankan Gradle. Tidak menyentuh 42-G2 / berkas 43-S / berkas agen lain.

## Keputusan kecil
- Nama kelas lama dipertahankan (`MandiriBoardScreen`/`JaringScreen` kini `Page`; `SuasanaScreen`/`TanggaCatatanScreen`
  kini panel) agar riwayat git utuh; tidak ada berkas `.deactivation` dari label ini.
- Buka murid lewat server (`DISCIPLE_OPEN eid`, rute `OpenScreen.DISCIPLE` -> `cadangan`) setelah `HubNav.ingatSub`,
  jadi tetap jalan selama transisi; murid jauh (`F_JAUH`) atau tak termuat -> buku harian (perbaikan R17 kecil).
- Baris Tangga hanya punya nama: dicocokkan dengan baris papan aula (tanpa ubah server).
- Satu klik membuka (baris punya zona sendiri di atas zona pilih `DaftarGulir`); keyboard: pilih ↑↓ + Enter.

## Butuh dari modul lain
- M03 (Murid): sub id yang dituju: `jalan_hidup`, `hati`, `hubungan`, `buku_harian`. Dukung fokus `{"jiwa": soul}`
  (+`"murid"` opsional) untuk murid di luar jangkauan pada sub `buku_harian`; sub itu membaca `MandiriClient.halaman(soul)`
  / `MandiriClient.versi()` (MandiriClient tidak lagi memanggil `BukuHarianScreen.segarkan/bukaTanpaMinta`). Pasang
  `HatiTab`, `HubunganTab`, `JalanHidupTab` sebagai sub (tiga `addExtraTab` sudah dihapus). Pertahankan
  `HatiTab.SIFAT_ATLAS/STATE_RGB/AXIS_RGB` (paket) — dipakai `SuasanaScreen`. Pakai `PelukisIkatan` di `HubunganTab`.
- M05 (Ikhtisar): di `HallClient.init` panggil `MandiriBoardScreen.dipasang(MandiriBoardScreen.SUB_KABAR)` dan
  `dipasang(SUB_KEBIJAKAN)`; catatan: `Kronik` + `MandiriBoardScreen.kabar(MandiriBoardScreen.papan())` (jenis "murid"),
  `minta()` di `onShow`; identitas: `new MandiriBoardScreen.PanelKebijakan().gambar(l, kunci, papan, ...)` setelah
  `alasanKosong(papan) == null`.
- M08 (Kas): `dipasang(SUB_KAS)` + `MandiriBoardScreen.PanelKas` (sama polanya) di sub kas.
- M19/M20 (kartu warga, sub Pohon): pakai `PelukisIkatan` (G69).
- P3: hapus cabang sub transisi di `MandiriBoardScreen.subs()` (komentar `shortcut:`) bila M05/M08 sudah memasang.
- F43-M1: tidak ada rintisan; kunci lang lama yang kini tak dipakai dibiarkan (43.0.8):
  `kultivator.hub.card.{sekte_kepribadian_suasana,sekte_tangga_catatan,sekte_mandiri_jalan,sekte_hubungan_jaring}*`,
  `...mandiri.cerita.papan.{judul,tampil.murid(.tip),tampil.*.tip,kabar_waktu,kabar_kosong}`,
  `...kepribadian.suasana.judul`, `...hubungan.jaring.petunjuk` (`jaring.judul` tetap dipakai sebagai judul halaman).
