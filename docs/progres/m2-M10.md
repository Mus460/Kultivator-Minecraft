## Keputusan kecil
- Halaman Wilayah selalu tampil: sub Cabang berlaku untuk siapa saja (lembar server sendiri menulis "bukan anggota" +
  syarat), agar anggota sekte NPC tanpa aula tetap sampai ke Politik Cabang (G67). Sub lain menurut HallInfo.
- Sebelum HallInfo pertama, Pertahanan/Kebun/Langit dianggap berlaku (tidak membuka di Cabang lalu melompat).
- Lembar `gabung_politik` dari NPC (konteks) tidak berumah di Wilayah (mount tanpa registrasi); tab Cabang tetap
  terjangkau dari sub ini.
- Tetangga Langit tetap bagian bertumpuk di Langit (`shortcut:` di kode) sampai M11 memasukkannya ke Sekte Dunia.
- Kebun & Tambang satu gulir (data server memuat keduanya); jalan masuk "tambang" menggulir ke judul Tambang.
