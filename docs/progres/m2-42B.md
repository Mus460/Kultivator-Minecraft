## Hasil kunci
- `TokohKota`: registry `tempat/tokoh/*.json` (`{"tokoh":[...]}` format of cerita_isi_kota42.py: id, peran, perempuan, umur, watak, suara_tubuh, abadi, tempat, kebiasaan, keluarga, rupa, hewan, optional akar) -> registered into 38 `Tokoh` (new additive
  `Tokoh.daftarData`, so `jadi_tokoh`, 38 name plates, `Isian tokoh:` names and 42D's `CeritaApi.tandaiTokoh` accept 42 ids). Cast once per world on Hari Warga:
  ibukota/keliling -> first capital (`CeritaData.firstCapital`), kota34 -> nearest kind-34 town to it, tema_<x> -> first themed city of that theme. Best resident by
  role/sex/age/generated slot; never changes `Warga.peran` (the slot's role stays); sets tokoh, abadi, age, watak, suara, habits, akar (xiao_yu HEAVENLY); family links
  (ayah/ibu/anak/istri/suami real, households merged only when one side has no generated slot; guru/murid/sahabat/kin as bonds). `tick` tags live bodies
  (memory tokoh+watak, plate, `SosokApi.setRupa` of the role/`rupa`). `jadwalkanWafat` = story retirement (Lao Geng, Nenek Tang).
- `AkibatKota` registers the 14 `kota42.*` effects of the 42B-C arcs (kesan gosip kebiasaan nikah pindah calon saham nama_jalan harga resep pensiun warisi pakta jabatan;
  javadoc has the syntax) + a `HargaKota` event source for `kota42.harga`; `kota42.gosip` custom ids map to 42K predicates (pasangan_sumur SUKA, batas_sumur BENCI,
  seribu_jari/wayang_hilang MENCURI). `kota42.pindah` writes the Migrasi plan keys (pdKe/pdHari/pdSebab/pdRombongan) into `ArsipWarga.Catatan`.
- `TempatDialog`: every civilian enters the dialog path; SAPA sheet merges `BicaraWarga.lembar`; unknown ops go to `BicaraWarga.aksi`.
- lang `kota_hidup_bicara` (303 keys id+en).
