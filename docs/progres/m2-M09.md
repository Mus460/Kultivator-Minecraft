- Seksi Misi/Arena dan jenis Papan = baris chip (rupa `Saring`), bukan bilah tab ke-4.
- Pemilih tunggal (Tugas, Pencari Bakat, Bahtera, Hampa, Menara) mode daftar: klik baris = pilih (lebih sedikit klik).
- Kolom pemilih < 180 px (skala 4): tanda kanan disembunyikan agar nama terbaca (Tugas tetap menampilkan tugas pendek).
- Turnamen Murid+ (sekte NPC) tidak punya data/layar klien di kode -> sub arena hanya untuk pemilik aula.
- Topik bantuan: `aula`, `misi`, `turnamen` (sudah ada).
- Kunci lang lama tak dipakai lagi (dibiarkan): `kultivator.spine6.page.{duty,mission,arena}.short`,
  `kultivator.spine6.ui.section_picker`, `kultivator.sekte.misi.lapor.judul_layar`, `kultivator.sekte.turnamen.ui.{judul,
  berjalan,perunggu,berikutnya,hari,hari_elit,sepanjang_masa,sepanjang_baris}`.
