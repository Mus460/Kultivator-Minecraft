## Decisions
- 41 screens open with TempatLayar.bukaDi(player.blockPosition()) when there is no NPC (hub/command): writes allowed
  within 8 blocks of where opened (TempatLayar blocks writes on plain hub screens). Client screens override hanyaBaca().
- Ops without a contract method dispatch through GabungLayar.daftarAksi(layar, verb, aksi) (module override) before
  the 41U default; GabungLayar.addPengisi(layar, pengisi) lets modules add/override sheet keys after the build.
- Rank trials (Uji Ulang, Ujian Murid Dalam, top-3/misi A, heir election, elder trial, support, succession) are flags
  GabungLayar.tandaiLulus(k, pangkat) set by the module that runs them (cleared by the promotion).
- "Perguruanku" hub card is never locked (locked cards cannot be clicked): non-members get the Direktori.

## Butuh dari modul lain
1. 41B: body of `masuk/Lamaran.buka(player, sekte)` = `LembarLamaran.buka(player, sekte, -1)` (recruiter: its npcId);
   recruiter "Tanya tentang sekte" = `LembarDirektori.buka(player, sekte, npcId)`. Default `ajukan` records CALON data
   only: register `GabungLayar.daftarAksi(GabungLembar.Lamaran.LAYAR, "ajukan"|"batal", ...)` to add the Tanda Calon /
   gate call. Unlock Undangan from tournament sources with `addPengisi(Lamaran.LAYAR, ...)`. Shifu/Putusan: register
   with `GabungLayar.daftar(layar, builder)` and open with `GabungLayar.buka` (plain TempatLayar hub sessions refuse
   writes). Candidate traits -> addPengisi(Kartu.LAYAR) list `kartu.sifat`. Uji Ulang passed -> `tandaiLulus(k, LUAR)`.
   Test HUD: `GabungPayloads.kirimUjian(..., GabungLembar.HudUjian.data(J_TANGGA|J_HATI|J_WAWANCARA|J_TAMU, ...))`.
2. 41B-C: HUD bytes `HudUjian.data(J_CORAK + corak.ordinal(), ...)` per the table in GabungLembar.HudUjian.
3. 41A: promotion ceremony -> `daftarAksi(PohonPangkat.LAYAR, "ajukan", ...)` (default pays + setPangkat);
   Keluar ceremonies -> `daftarAksi(Kartu.LAYAR, "pamit"|"pamit_paksa"|"belot", ...)` (defaults call GabungApi.keluar);
   a due hearing -> addPengisi(Kartu.LAYAR) `hukum.sidang` true; Ujian Murid Dalam / Ujian Tetua -> tandaiLulus.
   Player subs `direktori, info, kartu, pangkat, naik` are registered by GabungLayar.init (do not duplicate).
4. 41C: Jatah from the card -> `daftarAksi(Kartu.LAYAR, "jatah", ...)` (default message: collect at Balai Jasa);
   an A mission done -> `tandaiLulus(k, INTI)`.
5. 41C-K: tournament top 3 -> `tandaiLulus(k, INTI)`; next lesson -> addPengisi(Kartu.LAYAR) `shifu.pelajaran`;
   tournament title -> `kartu.gelar`.
6. 41D: heir election -> tandaiLulus(PEWARIS); elders' support -> WAKIL; succession -> KETUA; PeringkatSekte strength
