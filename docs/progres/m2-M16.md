## Keputusan kecil
- Purba = satu halaman, sub binatang | bencana; `BencanaPage` kini bagian sub (bukan Page) agar tidak ada basis kedua. Kunci halaman = kunci Puncak (bencana), sub binatang terkunci sampai naik (kunci kartu hub lama).
- Titah tetap bernama `TitahScreen` (nasib H: kelas tetap, basis Page). Halaman terkunci di bawah Dewa Abadi Sejati atau tanpa Segel di tas (aturan menu lama). "Pilih" = pilih + tutup Gulungan (untuk langsung merapal).
- Lelang tanpa kunci "naik" (kelas lembar bukan milik M16); server menolak tawaran di luar Alam Abadi dengan pesan, strip lembar menyebut alasannya.
- Ciptaan: Timpa slot dan Hapus = SegelKonfirmasi SEDANG (dulu klik kedua 4 s).

## Butuh dari modul lain
- **F43-M1 (`tempat/ui/UiTempatClient.kirim`, 43-S), WAJIB**: baris pertama badan metode:
  `if (dev.kultivator.client.abadi.LelangJembatan.kirim(layar, npcId, op)) { return true; }`
  Tanpa ini tawar/titip di Keabadian › Lelang tidak sampai (server mengabaikan op npcId -16, aman). M15 (`KotaJembatan`) kemungkinan butuh kait serupa: satu baris per jembatan.
- F43-M1 / P1 (`hub/HubNav.rute`, opsional): kasus `OpenScreen.TITAH` cukup `dev.kultivator.client.pusakalangit.TitahClient.openScreen(arg)` (kini `HubNav.buka` + fokus `{"titah": arg}`), agar titah yang diminta server ikut terpilih.
- M13 (`dunia/DuniaClient.openAbadi`, opsional): ganti isinya dengan `HubNav.buka(HubNav.tujuanAbadi(tab))`; lalu P1 boleh ganti nama `KeabadianScreen` -> .deactivation.

Sampai itu: tiga tombol titip semuanya menitip dengan nilai tetap (label "80 %/100 %/120 % · 1").
