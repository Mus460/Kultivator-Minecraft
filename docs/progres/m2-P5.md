## Uji 43.18 (P5; jalankan di permainan, 1366x768 skala 2/3/4)
1. Sekte › Kas & Toko: chip Kantor/Hari ini/7 hari/Sumber/Politik/Mandiri meluap dengan panah di 289 px; kolom bergulir
   (roda, ↑↓ PgUp PgDn Home End); Toko PK Aulaku: Beli 14 px; Perguruanku (chip Sumber): pemilih jumlah ← → + Tukar.
2. Klik NPC Paviliun Jasa -> Gulungan di Sekte › Kas & Toko › Toko PK, Sumber Perguruanku, chip "bersama <nama>" (baru).
3. Lembar politik dari NPC: tab Kas -> Kas › Politik Kas; Cabang -> Wilayah › Cabang; Perang -> Luar › Perang
   (Perguruanku); Majelis/Suksesi -> Anggota (TetuaClient).
4. Rak/Makam: klik paviliun/altar/nisan -> sub benar; Ambil/Abadikan = segel ringan; PgUp/PgDn/Home/End.
5. Kegiatan: Tab dari koin -> chip jenis Papan -> isi lembar; Shift+Tab kembali ke chip; Misi 7 chip seksi; item
   Gulungan Laporan -> rinci laporan, Esc kembali; Turnamen Terima tetap di halaman (R12).
6. Wilayah: Pertahanan "Memuat…" lalu angka; Desa SEMPIT daftar -> kartu -> Esc; Kebun "Memuat…" lalu petak, segel 16x12,
   pemilih pekerja sembul (Esc batal); Langit: Undang (pemain daring + nama), Tetangga -> "Lihat di Sekte Dunia ›".
7. Luar: Sekte Dunia (cari `/`, chip aliran, urut), Lamar -> Di Sini Lamaran teks 1.0 + "‹ Sekte Dunia"; Perang
   "Nyatakan Perang" = segel berat; Seteru aksi = sedang; Seteru tanpa seteru/sahabat -> satu keadaan kosong.
8. `grep -rn "pose().scale\|setScreen(new"` di berkas P5: kosong.
