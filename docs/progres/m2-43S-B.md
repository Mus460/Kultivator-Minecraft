## Butuh dari modul lain
- S-A: host memanggil `SlipTooltip.gambarAntrean(...)` paling akhir tiap bingkai (satu tooltip per bingkai) dan
  `Page.render` sudah meneruskan `Fokus.selesai`. Jangan tulis kunci `kultivator.gui43.kit.*` di fragmen `gui43`
  (sudah di `gui43_kit`, kunci ganda menggagalkan mergeLang). `Page.Lapisan` tidak diperlukan: `Page.konfirmasi`
  memakai `Fokus.konfirmasi` (SegelKonfirmasi milik Fokus); `PemilihOrang` mode sembul digambar di `lukis(l)` halaman,
  halaman meneruskan Esc lewat `mundur()` -> `pemilih.tutup()`.
- P1: `.deactivation` salinan kit 38 (`tempat/ui/kit/{CincinWaktu, KartuBarang, Potret, Pratinjau3D, LencanaPangkat,
  PapanSkor, DaftarGulir, KeadaanKosong, KeadaanTerkunci, LabelHarga, PemilihJumlah, KotakCari, TombolAksi, ...}`) setelah
  pengimpor pindah ke `screen/ui`.
- F43-S: build B0 memverifikasi kompilasi (belum dikompilasi oleh S-B).

## Catatan
- `KartuBarang`, `DaftarSekte`, `PapanMisi`, `Kronik`, `KartuHasil`, `PemilihOrang`, `DaftarPilihan` hanya cara imediat
  (`Lukis`); tidak ada bentuk `Widget` (halaman menggambar di `lukis(l)`).
- Teks kit 1.0 (judul 1.5, stempel KartuHasil 1.5); skala 0.6-0.85 lama dihapus dari salinan.
