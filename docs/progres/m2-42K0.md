## Design choices other modules must know
- `Cakap.sesi` returns null when the engine is off or the NPC is no warga; 42B falls back to the 38 greeting sheet.
- `Cakap.sapa` stub returns `kultivator.cerita.sapa.umum` (no call to `Kalimat`, so 42K's `Kalimat.sapa -> Cakap.sapa`
  forwarding cannot recurse).
- Players inside facts/gossip are player indices (`Rujuk.pemain(idx)`, table `WargaData.pemain` of 42A), not UUIDs.
- Data files may carry `_`-prefixed comment keys (`"_catatan"`); loaders ignore them, `cek_cakap.py` must allow them.
- SavedData `kultivator:kota_cakap` (42.5A.12) is 42K's to place (e.g. inside `Pengetahuan`); `CakapData` is formats only.
