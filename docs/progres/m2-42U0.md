## Decisions taken (contract notes)
- Remote sessions (npcId -1, no anchor) only pass LembarKunci read verbs, so 42 screens select with `tab:TAB:ARG` and
  page/filter with `halaman:N:SARING:CARI`; cross-screen jumps from remote = select, then `lihatDariHub(other)`.
- Enum values of other modules (KodeWajah, Kenangan, JenisHubungan, Kategori, JenisUpacara, Niat, Nada) travel as
  lowercase names; rows also carry `nama` T so new values still render.
- Pratinjau3D cannot draw structures: kavling preview = `siluet` (heightmap + top colours, <= 32x32); rumah = `denah`.
- `kota_sekte` hub card opens `pakta` (tabs pakta/bela/murid/cabang = "Sekte di Kota"); id has no `sekte_` prefix.
- Design text says "17 screens" (= 16 Lembar classes + KotaLembar); 42.11 actually lists 18 ids, plus `kota_milikku`.
