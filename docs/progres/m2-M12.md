## Keputusan kecil
- Nama kelas lama tetap (`PetaScreen`, `HelmScreen` kini `Page`); tidak ada `.deactivation` dari label ini.
- Tab lembar peta_kota menjadi sub Peta (Kota, Layanan, Tokoh, Acara) agar tidak ada bilah tab tingkat 4.
- Klik kanan kertas tetap = taruh tanda, juga di mode berlayar (satu arti); berlayar lewat kartu.
- Tombol inventaris tidak lagi menutup Kemudi (E = halaman berikutnya di Gulungan); Esc/V menutup.

- P6: G23 peta mini (Teleport/KafilahTema/BukuKas/Kapal/Ziarah, berkas M08/M19/M20) belum memanggil pelukis bersama;
  `PetaPainter.mini` tidak dibuat (belum ada pemanggil).
