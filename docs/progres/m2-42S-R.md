# m2-42S-R — ragam harian (42-G1)

Scope (jadwal row 42S-R, design 42.4A.3-42.4A.6): `dunia/kota42/ragam/{KumpulanKegiatan, RencanaHarian, Selingan,
Belokan, KegiatanKelompok, IramaMingguan}`, data `data/kultivator/tempat/ragam/{selingan.json, belokan.json, peran/*.json}`,
lang `kota_hidup_ragam2`. Must not touch 42S files (RagamData, PetaZona, Kapasitas, Penyeimbang, PemilihTubuh,
MetrikRagam, RagamUji, KotaRagam), hidup/** (hooks only), no Gradle.

## Design decisions (fixed)
- Overrider registered directly `Jadwal.addPenimpa(URUT_RENCANA, RencanaHarian::timpa)` (no dependency on 42A's bridge
  timing); Warga resolved via `WargaApi.warga(situs, id)` (null -> resident seed, neutral traits).
- Plan per resident per day, built lazily: round sampled every 10 minutes (`Jadwal.kegiatan`, CERAH, no event)
  -> blocks KERJA/BEBAS/MAKAN/MALAM (sleep, indoors, waking, wash, open/close stall, school = untouched). Core work with
  clip `@peran` returns null (round + ramai keep the shop, trade, calls). Yesterday's plan rebuilt without its own
  yesterday (no storage). Build budget 16 plans per tick (dawn in the capital spreads over ~2 s).
- Times: `Langkah.mulai/akhir` = world minutes after 06:00 (place time; the 38 day starts at tick 0 = 06:00);
  `RencanaHarian.jam(m)` formats them.
- Groups in place time (members switch together), goal `@kelompok:<day>:<gid>:<turn>`; turns `@belok:x,y,z,h[,d]`;
  both placed by own `TempatHuni.Penyeimbang`s that answer only their prefix (42S's balancer skips them: not in
  `zona.json` "umum").
- Activity signature = key + clip + variant (two chats that look alike count as one); outside core work an activity is
  never planned more than twice a day. New activity keys `rg_<id>`; existing 38 keys reused (obrol, minum_teh, catur...).

  call `RencanaHarian.lupakan(situs)` + `KegiatanKelompok.lupakan(situs)` when a place's residents change mid-day.

  mean + habits + seeded spread).
