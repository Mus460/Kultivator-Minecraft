Label M20. Lingkup: 19 lembar tema 38 sebagai halaman Di Sini (43.8.3, 43.12.4) + prompt `gabung_putusan` /
`gabung_shifu` (43.8.2). Berkas milik: `tempat/ui/tema/**` kecuali `LayarBukuDagang`, `TemaHub`; `TemaUi`, `TemaUiClient`;
`sekte/gabung/ui/layar/{LayarPutusan, LayarShifu}`. Kelas klien 42 dibatalkan (43.16.6). `LayarTemaDasar` = berkas 43-S
(P1) -> tidak disentuh; pembantu kit tunggal di kelas baru `tema/TemaHalaman` (turunan, pola `LayarDirektori` M11).
Tidak menjalankan Gradle. Tidak menyentuh 42-G2 (suntingan 42U-2 di LayarPasarGelap/LayarTaruhan dipertahankan).

## Pendekatan
Setiap lembar menggambar dengan kit tunggal `screen/ui` lewat `TemaHalaman`: `drawBehind` hanya menerapkan lembar
(`tabSekarang()` + `isi(null,..)` -> hook lembarBaru/tabGanti), isi di `lukisTema(Lukis,..)` dari `lukis(Lukis)`, masukan
ke `fokusRing` (+ `spasi()`/`tombolLain()` lembar). Overload bernama sama (`tombolOp`, `tombol`, `kosong`, `subjudul`,
`barisNilai`, `sumur`, `strip`, `tengah`, `pita`, `toko`, `Toko`, `DetailEkstra`) memakai `screen/ui.Lukis`.
Teks 1.0/1.5 saja (43.0.5), tombol >= 16x12 (`TalismanButton.gambar`), `Bilah` (G61), `KartuHasil` (G65),
`DaftarPilihan` (G59), `KartuBarang`/`LabelHarga`/`PemilihJumlah` (G19), `Palette`/`Glyphs.Atlas` (G33).
SEMPIT (1366x768 skala 4, isi ~285x148): daftar penuh + rinci menggantikan daftar (Enter/klik kedua, Esc/kembali
kepala = `rinci()`/`mundur()`), atau gambar sebagai kolom ramping di kiri; baris yang tak muat pindah ke tooltip.
Putusan/Shifu (turunan `LayarGabungDasar`, berkas 43-S) memakai pola `LayarDirektori`: `drawBehind` -> `tabSekarang()`,
gambar di `lukis(Lukis)`, masukan ke `fokusRing`; strip sekte versi kit tunggal = `LayarPutusan.kepalaSekte(l, lembar, ..)`.
