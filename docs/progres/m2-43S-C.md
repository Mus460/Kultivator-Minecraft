## Keputusan kecil (untuk F43-S)
- Tab lembar di Di Sini tampil sebagai sub (host hanya punya satu halaman Di Sini), bukan koin seperti teks 43.12.4.
- Memori sub Di Sini: `DiSini` memanggil `HubNav.ingatSub("di_sini", tab)` (id halaman Di Sini di `CultivationScreen`)
  agar host membuka tab yang diminta lembar. Jangan ganti id itu tanpa menyesuaikan `DiSini.ID_DI_SINI`.
- Server hanya punya satu sesi per pemain: tampilan baca-saja halaman rumah mengambil alih sesi NPC; sesi NPC diminta
  lagi saat Di Sini tampil kembali (NPC) atau konteks berakhir (jangkar).
- `uji ui skala` diterapkan di dalam kotak halaman lembar (bukan seluruh Gulungan seperti 43.0.5).
