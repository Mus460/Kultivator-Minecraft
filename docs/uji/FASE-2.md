# Checklist uji Fase 2 — akar spiritual, Jalan Dao, teknik, kitab teknik

Persiapan: dunia dengan cheat aktif. Di antara percobaan teknik: `/kultivasi debug fill` (Qi penuh) dan
`/kultivasi debug technique cooldowns reset`. Monster uji: `/summon minecraft:zombie ~4 ~ ~`.

## A. Akar spiritual & upacara uji akar
1. `/kultivasi debug reset` lalu `/kultivasi root test` (atau jimat "Uji akar spiritual" di layar `'`; layar
   menutup sendiri). Lingkaran batu penguji (jari-jari 3) muncul; tiap ±1 detik satu batu dibaca: batu elemenmu menyala
   tinggi dengan dentang naik, batu lain meredup. Detik ke-8: judul "Akar Mutu …", pencapaian "Batu yang Mengetahui".
2. Selama upacara, layar info belum menampilkan akar ("sedang dibaca oleh batu penguji…").
3. Keluar dunia di detik ke-3 lalu masuk lagi → upacara diputar ulang dengan akar yang SAMA (tidak bisa undi ulang).
4. Elemen mutan: `/kultivasi debug set root heavenly lightning fire` lalu `/kultivasi debug root replay` → 9 batu,
   batu Petir menyala, judul "Akar Mutu Surgawi". Akar satu elemen (`set root mid water`) → hanya 5 batu.
5. `/kultivasi root info` → akar, pengali kecepatan, afinitas Dao.
6. Pil Pembersih Sumsum: resep tanpa pola (irisan semangka berkilau + air mata ghast + apel emas + pecahan kecubung +
   tepung tulang). Klik kanan (akar sudah diuji): Mual + Kelaparan II 8 detik, partikel hitam merembes, lalu kilat putih,
   mutu naik satu tingkat (25% peluang membuang satu elemen kalau elemen ≥3). Mutu Surgawi yang sudah murni → pil tidak
   terpakai.

## B. Jalan Dao
7. `/kultivasi debug set root high metal`, `/kultivasi debug set realm golden_core`, diam beberapa detik → layar Akar &
   Dao terbuka sekali (tidak saat bertarung/meditasi), plus pilihan Dao di chat yang bisa diklik.
8. `/kultivasi dao choose sword` (atau klik trigram Bagua dua kali) → cincin delapan trigram, judul "Kamu menapaki Dao
   Pedang", teknik Tebasan Qi Pedang langsung dipelajari. Pilihan kedua ditolak. Di bawah Inti Emas ditolak.
9. `/kultivasi dao info` → Pemahaman 7,5% (5 × 1,5 karena akar Logam selaras).
10. Pemahaman naik dari aksi Dao (dibatasi tiap 2 detik): bunuh dengan pedang (Pedang), monster terbakar (Api), bioma
    bersalju (Es), saat badai petir (Petir), dipukul monster (Tubuh), darah pulih / memberi makan hewan / tepung tulang
    (Kehidupan), jongkok/malam (Bayangan), ender pearl / berada di End (Ruang).
11. Naik tingkat: `/kultivasi debug dao comprehension sword 29.97` lalu bunuh zombie dengan pedang → "Pemahaman Besar".

## C. Kitab teknik (buku enchant vanilla)
12. `/give @s minecraft:enchanted_book[stored_enchantments={"minecraft:sharpness":5}]` → tooltip "Kitab teknik: Seribu
    Pedang (Dao Pedang, Jiwa Baru Lahir, Pemahaman 30%)".
13. Jongkok + klik kanan saat syarat belum terpenuhi (Dao sendiri) → buku habis, +Pemahaman, daftar syarat yang kurang.
14. `/kultivasi debug set realm nascent_soul`, `/kultivasi debug dao comprehension sword 30`, buku sharpness lagi →
    "Kamu memahami kitab teknik: Seribu Pedang!".
15. Buku Dao lain (fire_aspect saat Dao Pedang) → ditolak dengan alasan, buku TIDAK hilang. Smite → Telapak Buddha
    (universal, bisa tanpa Dao). Buku biasa (unbreaking) → +30 kultivasi. Tanpa jongkok → tidak terjadi apa-apa.

## D. Teknik universal
16. `/kultivasi debug set realm qi_refining` → Langkah Awan + Telapak Qi dipelajari. `,` `.` untuk memilih, `G` untuk
    memakai. Telapak Qi berhenti di dinding; villager/serigala jinak/babi/pemain lain tidak pernah terluka.
17. Langkah Awan: lompat lalu tekan spasi lagi di udara (Pemurnian Qi 1×, Fondasi 2×, Inti Emas+ 3×). Lompat dari
    tebing tinggi + Langkah Awan → mendarat tanpa luka jatuh.
18. Pedang Terbang (Fondasi, butuh pedang di inventaris): tekan `\` → benar-benar terbang, Qi terkuras tiap detik.
    Tekan `\` lagi / Qi habis / dipukul monster → turun dengan Slow Falling. Logout saat terbang lalu login →
    tidak bisa terbang lagi di survival. Ganti ke creative lalu survival → terbang survival tidak tertinggal.
19. Indra Ilahi (Jiwa Baru Lahir): gelombang ungu 48 blok, monster bercahaya 12 detik, chat ringkasan bijih
    ("2 berlian, 14 besi…"), titik warna menunjuk arah bijih.
20. Telapak Buddha (Inti Emas, dari buku smite): telapak emas raksasa turun di titik yang dilihat, monster terhempas.
21. Wujud Dharma (Transformasi Dewa): tubuh 2× besar 30 detik, Strength II + Resistance I, jangkauan +2. Di ruang
    sempit ditolak / berakhir sendiri, tidak tercekik dinding.
22. Wilayah Dao (Penyatuan Dao): kubah partikel radius 10 selama 20 detik mengikuti pemain; efek tergantung Dao.

## E. 16 teknik khas Dao (Jiwa Baru Lahir, `/kultivasi debug set dao <dao>` + `/kultivasi debug learn <teknik>`)
23. Pedang: Tebasan Qi Pedang (bulan sabit 16 blok), Seribu Pedang (hujan pedang cahaya 4 detik).
24. Api: Telapak Api (kerucut 7 blok, membakar monster saja; rumput/kayu TIDAK terbakar), Api Phoenix (phoenix terbang
    24 blok). Monster terbakar di dekat salju bubuk/kuali air dipadamkan dulu supaya blok tidak berubah.
25. Es: Lotus Es (membekukan tanpa blok es), Penjara Gletser (mengurung 8 detik; creeper tidak meledak).
26. Petir: Telapak Petir (kilat partikel berantai ke 4 monster), Petir Surgawi (8 kilat). Penangkal petir tidak menyala.
27. Tubuh: Tubuh Besi (Resistance II, tidak terdorong, memantulkan 30% pukulan), Hentakan Gunung (monster terlempar ke
    atas; ladang dan telur penyu tidak rusak saat mereka jatuh).
28. Kehidupan: Mata Air Kehidupan (sembuh 40% + hapus racun, anjing jinak ikut sembuh), Serap Kehidupan.
29. Bayangan/Angin: Langkah Bayangan (muncul di belakang monster, pukulan berikutnya 2×; ditolak untuk creeper),
    Badai Angin (monster terlempar + kamu tak terlihat & cepat 6 detik).
30. Ruang: Kedipan Ruang (teleport ke titik yang dilihat, ditolak ke langit/lava/tempat berbahaya), Penjara Ruang.

## F. Umum
31. Selama semua uji: tidak ada blok yang terbakar, rusak, atau berubah; cuaca tidak berubah.
32. Kualitas Efek Minimal / Normal / Maksimal (layar `'` → Pengaturan) terasa bedanya di semua teknik.
33. Bahasa Indonesia & English: tidak ada teks mentah `kultivator.xxx`.
